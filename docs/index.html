How it works

01

Make a run

Use any tool: savestate TAS tools, scripts, search, or patience. Any input on any frame is allowed. The game itself stays unchanged.

02

Open a pull request

npm run add turns your recording into a run file. Commit it and open a pull request. Full guide.

03

CI replays it

The bot downloads the official engine from kodub.com, replays your run, and checks every checkpoint and the exact finish frame. Merged runs go on the board.

Think you can beat a time?

Every record here is open. A tie goes to the earlier run.
